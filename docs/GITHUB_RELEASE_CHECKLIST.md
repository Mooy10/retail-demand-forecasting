- [ ] Secrets removed.
- [ ] `.gitignore` validated.
- [ ] README renders correctly.
- [ ] Images load from `docs/images/`.
- [ ] Diagrams load from `docs/`.
- [ ] Notebooks open.
- [ ] Tests pass.
- [ ] Dashboard starts locally.
- [ ] Internal links work.
- [ ] MIT license included.
- [ ] Disclaimer included.
- [ ] Repository does not include `data/raw`.
- [ ] Repository does not include `.venv`.
- [ ] Repository does not include oversized generated outputs.
- [ ] Main branch is clean.
- [ ] Final commit is ready.
