# Contributing

This repository is a professional portfolio project. Contributions are welcome when they improve clarity, reproducibility, documentation, or code quality.

## Guidelines

- Do not commit raw data, processed data, trained models, credentials, or local environment files.
- Keep business claims clearly separated from simulated assumptions.
- Run tests before opening a pull request:

```powershell
python -m pytest tests -p no:cacheprovider -q
```

## Suggested Contribution Areas

- Documentation improvements.
- Additional tests.
- Cleaner dashboard components.
- Reproducibility improvements.
- Alternative validation summaries.
